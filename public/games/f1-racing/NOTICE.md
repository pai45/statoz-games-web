# F1 Racing — official Crazy Grand Prix embed

F1 Racing is the user-requested StatOz Games Web catalog title for the original Crazy Grand Prix game. It is loaded through its official public embed at https://www.crazygames.com/embed/crazy-grand-prix. The native build retains the original title, art, controls, modes, notices, hosting and services. No affiliation with Formula 1 is claimed.

The native code, artwork, audio and game content belong to their original rights holders. No proprietary engine binaries, extracted assets, or third-party cover artwork are bundled. The catalog uses the project-owned Grand Prix Dash cover.

The browser build has a site lock. Localhost execution was refused; no site lock was removed or bypassed. Local SDK/input experiments were removed from the maintained runtime. No native code was patched. The game needs internet access and keyboard driving. There is no verified touch-driving bridge. Native multiplayer, ads, account/storage and progress depend on the game provider and have not all been verified.
