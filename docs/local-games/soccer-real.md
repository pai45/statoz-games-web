# Soccer REAL

Play `/play/soccer-real`. The original shipped Three.js game, player/stadium GLBs, 59 native animations, 23 recovered textures and local CPU quick-match/tournament flow are installed locally. `scripts/build-soccer-real-assets.mjs` verifies immutable `originals/` then writes the authored local adapter plus transformed native client with hashes.

The original online entry is redirected to local CPU play and labelled accordingly. Matchmaking/socket services are not started. Interstitials continue without ads; optional mid-match advertising offers take the normal no-boost continuation. Rewarded-ad failure does not fabricate inventory. Native local records/settings persist through the existing host account store. Frame/audio/input lifecycle is local and source/session checked.

The original movement, kick/keeper/AI/score implementation remains shipped JavaScript. Its full editable export library, model curves, embedded textures and exact source atlas are `.local-game-assets/soccer-real`, with a public dissection manifest. No original authoring repository/backend or offline network multiplayer is claimed. [Shared checks and limits](README.md).
