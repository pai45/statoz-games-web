# Retro Football 2 — local integration

Retro Football 2 is a separate Future Games Web catalog entry at `/play/retro-football-2/`. Its native game is Super Sidekicks 2 — The World Championship / Tokuten Ou 2 (Neo Geo NGM-061/NGH-061). Existing Retro Football and Street Hoop remain available with their own identities and storage.

This is the complete cartridge running through local EmulatorJS 4.2.3 / FBNeo, not a reconstruction of its mechanics. Native team selection, tournament, player motion, sound and rules remain owned by that original game. The host does not fabricate match results, XP or economy rewards.

The new mobile shell supports shared handheld side controls or over-screen controls, landscape/fullscreen, eight-way movement with dead-zone hysteresis, independent A/B/C touches, at least 44 px targets, left-handed arrangement, adjustable action size and native volume. Minimum 50 ms action taps span emulation polls. Cancellation, blur, pause, rotation and disposal clear held inputs. Native emulation pauses rather than continuing behind settings. Keyboard: arrows/WASD, A=J/Z, B=K/X, C=L/C, credit=Right Shift/5, Start=Enter, pause=P/Escape. A confirms native menus; the native name-entry screen uses Start to finish. The shell's Coin adds a simulated credit and never initiates payment.

The native help screen documents A slide, B tackle/rough play and C action-player shift on defense. Offense uses A shoot/low pass, B high pass and C short kick. These meanings remain context-dependent native actions; the host does not remap C to another A/B action. FBNeo RetroPad ids are A=0, B=8, C=1; native controls were exercised during local verification. The BIOS boots before the wrapper sends credit/Start. Local core settings enable the game's Free_play option; no native time/AI tuning or frame acceleration is applied.

All playback resources are local; there is no RetroGames.cc iframe or advertisement. Threaded emulation, shaders and rewind are disabled to reduce mobile work and avoid requiring cross-origin isolation. A legacy core build is included for WebGL fallback. Physical-device performance and iOS audio/fullscreen behavior still require device testing.

`arcade/assets-manifest.json` records source identities, sizes and SHA-256. To restore a workstation, retain an authorized local backup containing `data/` and `roms/`, then run `node scripts/install-retro-football-2-assets.mjs <backup-directory>`. All files are checked before copying. The script never downloads proprietary files. Host account hashes namespace native IndexedDB; wrapper preferences/save keys are separate from the other games. No account identifier is sent off-device.
