# Apex Sprint Mobile

> Removed from Future Games Web on 28 October 2026 at the user's request. The catalog entry, renderer registration and direct play route are retired. Source is retained as local development history.

Original Canvas arcade racer at `/play/apex-mobile`, separate from the Crazy Grand Prix embed. Three laps on an invented circuit with five deterministic opponents, off-track slowdown and contact penalties. No licensed teams, circuits or third-party game assets. Shared project-owned Grand Prix Dash catalog art is reused.

Two-thumb pointer controls support simultaneous steering and gas/brake. Keyboard: arrows/WASD, Escape pauses. Losing focus or hiding the page pauses and releases input. Rendering uses a capped 1.5 device pixel ratio; simulation uses fixed 60 Hz steps with capped catch-up. The existing mobile landscape viewport rotates portrait phones and handles browser resizing. Fullscreen is user initiated and browser dependent; iOS may retain browser chrome. Race state stays in memory; no persistent saves or network services.
