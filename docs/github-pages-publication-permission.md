# GitHub Pages publication permission

On 26 October 2026, the project owner confirmed permission to publish the Street Hoop, Super Sidekicks 2 and Stick Cricket game files and the required arcade BIOS on the Future Games Web GitHub Pages site. The original game files and BIOS retain their respective owners' rights; this confirmation is not an independently verified licence. Earlier local-only statements in the integration notes describe the status before this confirmation.
