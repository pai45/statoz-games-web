# Archery Test — original Archery Master local integration

Open Games → Archery → Archery Test (`/play/archery-test`). The maintained shell lives in `src/features/games/archery-test`; native files live in `public/games/archery-test/native`. Designer stores the REA research. No upstream/card_game checkout is a runtime dependency.

The original unchanged game/engine/vendor bundles retain native graphics, hand/bow animation, camera, scoring, equipment and all 1,000 numbered level declarations. Available assets for four declared maps, eight target types, four bows and five arrows are installed across all three quality tiers. These declarations and resource closure do not constitute a full 1,000-level playthrough.

The host supports portrait phones directly. Hold until the bow is drawn, drag to aim, then release. Use the right half on touch devices. The landscape view preserves the original portrait target frame. Host Exit, Pause, Settings and volume remain accessible above the native screen. Pause/background/cancel clears native aiming state and sleeps the native loop. Native touch controls remain game-owned. The settings dialog supports keyboard focus and Escape.

An authored local platform interface replaces remote SDK/account services, retains native player data/stat writes in per-game/per-account local storage and uses device-only local player identities. The configured local data-store path is used. No external SDK, ads, analytics or notification requests are sent. Native attempts to reach online notification services are refused by the adapter. Online challenges, leaderboards, purchases and platform rewards are unavailable; rewarded ads reject instead of granting false rewards. The original earned local progression remains unchanged.

Native code/art ownership remains with SUN.STUDIO and original rights holders. No redistribution license has been supplied; ignored native assets are local reference artifacts and are not published. The recorded source build is `https://archery-master.game-files.crazygames.com/archery-master/9/`. The native page release identifier is 65; do not infer a semantic version from the directory. `NOTICE.md` and `assets-manifest.json` retain provenance, SHA-256 and an explicit rendering fallback: the source's 1024 EnvironmentA terrain returns 404, so its available exact 512 bytes serve that quality path. Gameplay and level records are unchanged.

Build: `npm run build:archery-test`. A build verifies native resource identity first; a fresh clone requires the local backup restored via `node scripts/install-archery-test-assets.mjs <backup-directory-containing-native>`. Verify with `--verify`. No proprietary files are downloaded by that installer.

Checks: `npm run test:archery-test`, `npm run test:archery-test:browser`, `npm run test:device-assets`, `npm run typecheck`, `npm run lint`, `npm run build:pages`, then `node scripts/check-archery-test-route.mjs`. Browser captures/results live in `test-results/archery-test-integration` and `test-results/archery-test-route`. Android Chrome emulation verified real touch shots to 24/21, earned Level 2 persistence, reload and account separation, native pause, volume and landscape sizing with no page errors, failed asset requests or remote HTTP requests. Physical Android/iOS testing remains.
