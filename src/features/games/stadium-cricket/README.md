# Stadium Cricket

Local integration of Cricket Masters — Stadium Edition 2.1 from RealOmlit/CricketV2, pinned at cb19e595d5a00a2764a6a5cb4b20fc48a2a733bc.

## Ownership and permission

The user confirmed permission to import and adapt this game on 2026-10-22. The original work has no published blanket license. SOURCE.json records that permission and SHA-256 hashes of all imported files. Preserve CREDITS.md and assets/THREE-LICENSE.txt.

## Boundaries

The imported source in vendor/cricketv2 is the unchanged upstream baseline. Game rules, timing, random shot direction, all four roles, 3D models, source UI and synthesized audio are retained. The StatOz lobby, isolated frame, storage, lifecycle and bundle packaging live outside the baseline. build-stadium-cricket.mjs verifies the baseline hashes, inlines the original CSS and scripts and preserves Three.js r160.

Saves use the versioned bundle schema under an account-specific Stadium Cricket key. No Final Over progress is converted, and no card gate, XP, coin award or economy event is added. Invalid saved data is preserved and does not get silently overwritten. Final Over's runtime is retired from the launcher; history, statistics and shared kit dependencies remain.

## Known upstream limitations

README aiming keys are stale: source gameplay chooses direction randomly at contact. Keeper and fielder modes are timing challenges. Best-score keys are shared across roles and maximize runs even in defending modes; this behavior is retained for fidelity and needs a separate agreed iteration. The source uses a variable frame step capped at 50 ms; it has not been rewritten as a deterministic engine. Parity checks use controlled randomness and frame timestamps instead.

## Build and validation

Run npm run build:stadium-cricket, npm run test:stadium-cricket, npm run typecheck, npm run lint and npm run build. The bundle has no remote resource dependency. Browser evidence and screenshots are generated by scripts/verify-stadium-cricket.mjs under test-results/stadium-cricket, with the lobby capture under public/games/stadium-cricket. Verify both root and subdirectory exports. No publication is part of this integration.
